# Changelog

All notable changes to Athena are documented here.

## 0.1.0-beta - 2026-08-25

Initial public learning-project release.

### Included

- Local Ollama chat with Fast, Balanced and Max modes
- Persistent conversation history, summarization, stop and redo
- File search, document extraction, OCR and semantic document search
- Evidence-grounded file, system, code and web answers
- Keyless weather, finance and exchange-rate lookups
- General web research with source display
- Image understanding and generated-code execution
- Live processing pipeline, token accounting and responsive browser UI
- Deterministic regression suite and real-model evaluation scripts

### Known limitations

- Web research quality depends on public search results and site availability
- Generated Python is not sandboxed
- Conversations are local but unencrypted
- No enforced network-off mode or folder allowlist yet
- Small local models can still misunderstand or answer incorrectly
